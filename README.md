# Knowledge Base

Repository of research wikis and technical documentation meant to align our group understanding of GenAI tools and agentic workflows.

Conforms to the **AgentWikis** / [`llms.txt`](llms.txt) standard for human reading and AI agent retrieval.

## Topics

### [Herdr](herdr/README.md)
Terminal workspace manager and multiplexer for AI coding agents.
- [Overview & Architecture](herdr/overview.md): Core concepts, primitives, and agent lifecycle states (`idle`, `working`, `blocked`, `done`, `unknown`).
- [Containerized & Cloud Workspace Guide](herdr/setup-and-usage-guide.md): Docker, Coder, headless daemon, socket configuration, and SSH remote machine attachment.
- [Plugins & Extensions Catalog](herdr/plugins.md): Manifest contract, vetting checklist, top 10 ecosystem plugins, and active local plugins (`herdr-radar`, `web-ui`, `reviewr`, `memex`, `agent-router`, `auto-title`).
- [References & Sources](herdr/references.md): Annotated bibliography of upstream documentation.
